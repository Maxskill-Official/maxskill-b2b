# 로그인·채용관리 설정

## 1. Neon 데이터베이스 준비

1. Neon에서 PostgreSQL 프로젝트를 생성합니다.
2. 연결 문자열을 복사해 로컬 `.env.local`의 `DATABASE_URL`에 넣습니다.
3. 32자 이상의 무작위 문자열을 `AUTH_SECRET`에 넣습니다.
4. 다음 명령으로 테이블을 만들고 기존 채용공고를 이전합니다.

```powershell
npm run db:migrate
```

## 2. 직원 계정 1회 이전

사내 SQL Server에 접속 가능한 PC에서만 아래 환경변수를 `.env.local`에
설정합니다.

- `SOURCE_SQL_SERVER`
- `SOURCE_SQL_DATABASE` (`PJ_OT_DB`)
- `SOURCE_SQL_USER`
- `SOURCE_SQL_PASSWORD`

그 다음 실행합니다.

```powershell
npm run db:migrate-employees
```

이 스크립트는 재직자의 아이디·이름·비밀번호만 읽습니다. 비밀번호는 메모리에서
bcrypt 해시로 변환되며 파일이나 로그에 평문으로 기록되지 않습니다. 이금선,
박종현, 박경화 계정이 각각 정확히 하나씩 확인되지 않으면 이전을 중단합니다.

이전이 끝나면 `.env.local`에서 `SOURCE_SQL_*` 값을 제거합니다.

## 3. Vercel 설정

Vercel 프로젝트의 Environment Variables에 아래 두 값만 Production, Preview에
등록합니다.

- `DATABASE_URL`
- `AUTH_SECRET`

`SOURCE_SQL_*` 값은 Vercel에 등록하지 않습니다. 배포 후 `/login`에서 기존
교통비 관리 아이디·비밀번호로 로그인할 수 있습니다. 관리자 3명에게만
`/admin/jobs` 접근 권한이 있습니다.

## 4. 운영 확인

1. 일반 사원 계정으로 로그인되는지 확인합니다.
2. 일반 사원이 `/admin/jobs`에 접근할 수 없는지 확인합니다.
3. 관리자 3명 계정으로 공고 등록·수정·비공개·삭제를 확인합니다.
4. `/careers`와 공고 상세 화면에 변경 사항이 반영되는지 확인합니다.
5. 로그아웃 후 관리자 API와 화면에 접근할 수 없는지 확인합니다.
